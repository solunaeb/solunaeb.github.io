# 널 사랑할고양

느루(검은 고양이)와 함께 21일(2026.10.29 ~ 11.19)을 기다리는 방 꾸미기·편지 웹 앱(PWA).
모든 그림과 효과음은 코드로 만들어서 따로 필요한 이미지·소리 파일이 없습니다.

```
index.html, sw.js, manifest.webmanifest   앱 본체
css/ js/ fonts/ icons/                     화면·동작 코드 (fonts: 갈무리 글꼴, OFL 라이선스)
data/                                      암호화된 편지·음원 (자동 생성, GitHub 에 올라감)
content/letters.txt                        ✏️ 편지 원고 — 이 파일만 고치면 됨 (GitHub 에 안 올라감)
content/music/day01.mp3 ~ day21.mp3        🎵 음악 파일 (GitHub 에 안 올라감)
content/photos/                            📷 서랍·액자 사진 (GitHub 에 안 올라감)
tools/build_content.py                     원고 → data/ 암호화 빌드
push/, .github/workflows/push.yml          GitHub Actions 웹 푸시 알림
```

---

## 1. 내 컴퓨터에서 실행해 보기

서비스 워커와 암호화 기능 때문에 파일을 더블클릭하면 동작하지 않습니다. 폴더에서 아래 명령을 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.

## 2. 편지와 음악 넣기

1. `content/letters.txt` 를 열어 `=== DAY 1 ===` ~ `=== DAY 21 ===`, `=== FINALE ===` 아래에 편지를 씁니다.
   - `제목:` / `곡명:` 은 선택입니다. 곡명은 음반 상자와 재생 바에 표시돼요.
   - `---` 아래가 본문이고, 줄바꿈이 그대로 타자기에 찍힙니다.
   - FINALE 은 11월 19일 00:00 축하 화면에 나오는 마지막 메시지입니다.
2. 음악은 `content/music/day01.mp3` 처럼 이름을 맞춰 넣습니다. 없는 날은 그날 번호로 만든 8비트 멜로디가 대신 나와요.
3. 빌드합니다.
   ```bash
   pip install cryptography
   python tools/build_content.py
   ```
   Day 별 글자 수와 음악 연결 여부가 출력됩니다. 결과물은 `data/` 에 생깁니다.

### 사진 넣기 (서랍·액자)

| 위치 | 쓰이는 곳 |
|---|---|
| `content/photos/album/` | 첫 번째 서랍 — 사진 앨범 (여러 장, 파일 이름 순서로 넘겨 보기) |
| `content/photos/torch/` | 두 번째 서랍 — 횃불 사진 |
| `content/photos/buldak/` | 세 번째 서랍 — 까르보 불닭볶음면 사진 |
| `content/photos/frame.png` (jpg 가능) | 액자 — 방에서는 도트로, 누르면 원본 |

- png, jpg, webp 모두 됩니다. `01_첫 데이트.jpg` 처럼 이름을 지으면 "첫 데이트"가 사진 설명으로 나와요.
- `pip install pillow` 를 해 두면 빌드할 때 큰 사진을 긴 변 1600px 로 줄여 줍니다.
- 사진도 편지처럼 암호화되어 올라가지만, 저장소가 공개라서 "간단한" 보호 수준이라는 점은 같아요.

원고나 사진을 고칠 때마다 3번을 다시 실행하고 GitHub 에 올리면, 여자친구 기기에서는 다음에 앱을 열 때 자동으로 새 내용으로 바뀝니다.

## 3. GitHub Pages 로 배포

1. GitHub 에서 새 저장소(Public)를 만듭니다. 예: `neuru`
2. 이 폴더를 올립니다.
   ```bash
   git init
   git add .
   git commit -m "널 사랑할고양"
   git branch -M main
   git remote add origin https://github.com/<아이디>/neuru.git
   git push -u origin main
   ```
   `.gitignore` 덕분에 `letters.txt` 와 mp3 원본은 올라가지 않습니다. `git status` 로 한 번 확인해 주세요.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/neuru/` 에서 열립니다.

## 4. 테스트 모드

주소 뒤에 `?test` 를 붙여 열면(`.../neuru/?test`) 입장 후 비밀번호를 묻습니다. 기본 비밀번호는 `nuru1119` 입니다.

초록 벌레 버튼으로 가상 시각 이동(Day N 도착 10초 전, 다음 청소, 수료 직전·직후 등), 날씨 고정, 화분 성장 단계, 방 다시 어지르기, 가습기 물 비우기, 느루 재우기, 3시간 알림 미리 보기, 알림 테스트, 축하 연출, 진행 초기화를 할 수 있어요.

시간을 과거로 되돌리면 그 시각에 아직 도착하지 않았던 편지·LP 의 읽음/재생 기록은 자동으로 지워져서, 실제로 그날을 맞는 것과 똑같이 확인할 수 있어요. 다 보고 나면 **테스트 모드 끝내기**를 꼭 눌러 주세요.

**비밀번호 바꾸기**

```bash
python -c "import hashlib;print(hashlib.sha256(b'neuru:' + '새비밀번호'.encode()).hexdigest())"
```

나온 값을 `js/config.js` 의 `TEST_PASSWORD_HASH` 에 넣습니다.

## 5. 앱이 꺼져 있어도 오는 알림 (웹 푸시)

앱이 켜져 있을 때의 알림은 설정 없이 동작합니다. 앱이나 브라우저가 꺼져 있어도 폰에 알림이 오게 하려면 아래를 한 번만 해 주세요.

1. **키 만들기**: 테스트 모드 → *푸시 키 만들기*. `VAPID_PUBLIC_KEY` 와 `VAPID_PRIVATE_KEY` 가 나옵니다.
2. **공개키 넣기**: `js/config.js` 의 `VAPID_PUBLIC_KEY = ''` 에 공개키를 넣고 커밋·푸시합니다.
3. **GitHub 비밀값 등록**: 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   | 이름 | 값 |
   |---|---|
   | `VAPID_PUBLIC_KEY` | 1번의 공개키 |
   | `VAPID_PRIVATE_KEY` | 1번의 개인키 (코드에는 절대 넣지 말 것) |
   | `VAPID_SUBJECT` | `mailto:내이메일@example.com` |
   | `PUSH_SUBSCRIPTIONS` | 여자친구 기기들의 알림 연결 코드를 `[ ]` 로 묶은 것 |
4. **알림 연결 코드 받기**: 여자친구의 폰·PC 에서 앱을 열고 알림을 허용한 뒤, *설정(톱니바퀴) → 알림 → 알림 연결 코드 복사*. 기기가 두 대면 이렇게 넣습니다.
   ```json
   [{"endpoint":"...폰...","keys":{...}}, {"endpoint":"...PC...","keys":{...}}]
   ```
5. **확인**: 저장소 **Actions → 널 사랑할고양 알림 → Run workflow → test** 를 누르면 바로 테스트 알림이 갑니다.

동작 방식과 주의점:
- GitHub 예약 실행은 늦게 시작되는 일이 잦아서, 목표 시각 30분 전에 시작해 정각까지 기다렸다가 보냅니다. 그래도 GitHub 사정으로 몇 분 늦을 수는 있어요.
- 10/29 ~ 11/18 오전 10시·오후 10시(청소), 오후 11시(편지), 11/19 00:00(수료)에만 보내고 나머지 날에는 그냥 끝납니다.
- **공개 저장소에 60일 동안 커밋이 없으면 GitHub 가 예약 실행을 멈춥니다.** 입소 직전에 아무 커밋이나 하나 올려 두세요.
- 브라우저 데이터를 지우거나 앱을 지웠다 다시 설치하면 연결 코드가 바뀝니다. 그때는 4번을 다시 하면 돼요.
- 앱이 켜져 있을 때 뜨는 알림과 푸시 알림은 같은 태그를 써서 두 번 뜨지 않습니다.

## 5-1. 느루와 대화하기 (AI)

오른쪽 위 말풍선 버튼으로 느루와 대화할 수 있어요. 느루는 10월 29일부터 21일 동안 아기 고양이 → 어린 고양이 → 어른 고양이로 자라면서, 사랑에 대한 말도 점점 깊어집니다.

**키 넣기 (테스트 모드에서만 가능)**
1. https://aistudio.google.com 에 구글 계정으로 로그인 → **Get API key → Create API key** (무료, 카드 등록 없음)
2. 여자친구 기기에서 `?test` 로 테스트 모드에 들어가 **벌레 버튼 → 느루와 대화 (AI 키)** 에 붙여 넣기
3. **모델 칸은 비워 두세요.** 이 키로 쓸 수 있는 모델 중 가벼운 최신 Flash-Lite/Flash 를 자동으로 골라요
4. **연결 확인** → "연결 성공!"이 뜨면 **저장** → **테스트 모드 끝내기**

연결이 안 되면 결과 칸에 이유가 한국어로 나오고, 그 아래 [원본]에 구글이 보낸 오류가 그대로 보여요. **쓸 수 있는 모델 보기** 로 키가 실제로 접근할 수 있는 모델도 확인할 수 있어요.

**키를 안전하게 쓰는 방법 (꼭 해 두세요)**
- 키는 그 기기의 브라우저에만 저장되고 GitHub 에는 올라가지 않아요. 일반 설정 화면에는 "연결됨" 상태만 보여요.
- https://console.cloud.google.com/apis/credentials 에서 방금 만든 키를 열고:
  - **애플리케이션 제한사항 → 웹사이트** → `https://<아이디>.github.io/*` 추가 (다른 사이트에서 키를 가져가 써도 동작하지 않게)
  - **API 제한사항 → 키 제한** → *Generative Language API* 만 선택
  - 내 컴퓨터(`localhost`)에서도 시험해 보려면 `http://localhost:8000/*` 도 함께 추가
- 결제 수단을 등록하지 않은 무료 키라서, 혹시 새어 나가도 요금이 나오지 않고 사용량 제한에만 걸려요.
- 대화 내용은 답을 만들기 위해 구글 서버로 전송돼요. 무료 사용량의 대화는 서비스 개선에 쓰일 수 있으니 민감한 개인정보는 적지 않는 게 좋아요.
- 테스트 모드 비밀번호를 기본값(`nuru1119`)에서 꼭 바꿔 두세요. 키를 넣고 빼는 곳이 테스트 모드뿐이에요.

키가 없거나, 무료 사용량을 넘기거나, 인터넷이 끊기면 느루가 미리 써 둔 대사로 대답합니다. 느루가 부를 이름은 `js/config.js` 의 `HER_NAME`, `HIS_NAME` 으로 정할 수 있어요 (비워 두면 "너", "그 사람").

## 7. 알아 두면 좋은 것

- **시간 검증**: 온라인이면 GitHub Pages 서버가 응답에 담아 주는 시각(Date 헤더)으로 해금합니다. 기기 시계를 바꿔도 영향이 없어요. 오프라인이면 기기 시계를 쓰되, 마지막 서버 확인보다 48시간 넘게 앞서 있으면 그 지점에서 해금을 멈춥니다.
- **진행 상황(읽은 편지, 청소, 불·조명 상태)은 기기마다 따로** 저장됩니다. 폰과 PC 는 서로 공유되지 않아요. 브라우저 데이터를 지우면 초기화됩니다 (편지는 날짜가 지났으니 다시 모두 열려요).
- **암호화 수준**: 편지와 음악은 AES 로 암호화되어 저장소에서 바로 읽히지는 않지만, 복호화 키도 앱 안에 있으므로 개발자 도구를 파고들면 풀 수 있는 "간단한" 수준입니다. `js/config.js` 의 `CONTENT_SECRET` 을 바꾸면 반드시 `build_content.py` 를 다시 실행하세요.
- **코드를 고쳤다면** `sw.js` 의 `APP_VERSION` 숫자를 올려 주세요. 그래야 설치된 앱이 새 코드를 받습니다. (편지·음악만 바꿀 때는 자동으로 처리됨)
- **날짜를 바꾸려면** `js/config.js` 와 `push/send.mjs` 맨 위의 날짜를 함께 고치세요.
- 날씨는 Open-Meteo(서울)에서 30분마다 가져오고, 오프라인이면 마지막 날씨를 씁니다.
